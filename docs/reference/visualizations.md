# Visualizations

## `visualizations.allogreffes.graphs`

Plotly figure factory functions shared by all pages. Styling constants (colors, palette) are defined at the top of the module — reuse them for new figures (see [Adding a visualization](../guides/add-visualization.md)).

::: visualizations.allogreffes.graphs

## `visualizations.allogreffes.upsetjs_embed`

Pure-SVG interactive UpSet plot (no external JS dependency). Used for conditioning and prophylaxis combination analysis on the Procedures page.

::: visualizations.allogreffes.upsetjs_embed
